# R-05 / A2 — six-generator formal model, v0 candidate specification

**Date:** 2026-10-25 · **Status:** fully written **candidate transition-rule specification**, **NOT frozen** for Experiment 003, no implementation, numerical calibration, independent code review or model-recovery result.

This extends the [exact M/N/C and fixed-type matching fixtures](a2-analytical-oracle-20261025.md) to six *explicitly different candidate update/choice families* for scientific inspection. The previous hand-calculated reference remains the authoritative restricted oracle; adding four-player partner choice is a **proposed prospective synthetic treatment**, not a replication of the historical Galbiati dyadic experiment. It is also not proof that any two families are distinguishable, let alone all six.

## 1. One physical world shared by all generators

- **Agents/units:** initial minimum four agents, two undirected dyadic matches per period; independent **society/world seeds** are primary sampling units. A two-actor scripted-partner *fixture* is permitted as a separate diagnostic, never counted as an independent human counterfactual.
- **Time:** finite `t=1,…,T` (proposed first analytical study `T≤30` before any pilot). Each period: assign fine and matching information → optionally record **rankings/proposals** → generate pairing → reveal legitimate pre-action historical signal → simultaneous binary decisions `a_i,t∈{0,1}` → compute payoffs → update each learning state.
- **Exactly common material payoff:** `u_i,t = a_i,t + a_j,t − 2 a_i,t − f_t(1−a_i,t)`, for current matched partner `j`. Contribution-minus-defection material difference is `f_t−1`. The fine is **physical and externally assigned**, not an opinion about punishment. No hidden “institution choice” or partner-choice payoff is introduced in this A2 world.
- **Physical assignments (available to *every* family):** fine `f_t∈{0,1}`; matching protocol `z_t∈{random, choice}`; partner-history reveal `r_t∈{0,1}`; in a **synthetic diagnostic only**, a publicly identified scripted partner's *actual preceding action* may be assigned before the focal choice. A treatment selects the same physical action interface/world rules under every family; family-specific response is what differs.
- **Information and truthful message:** `s_{j,t}=a_{j,t-1}` is another agent's **actual** prior action when it exists and was publicly recorded. Under reveal `r=1` the focal agent observes `m_{i,t}=s_{j,t}`; under `r=0` the common neutral placeholder is `m_{i,t}=1/2` and **the actual hidden action must not leak** to the actor. At `t=1`, assign a seeded, *precommitted real* scripted/earlier training action; do **not** fabricate prior actions or advertise simulated lies as observations.
- **Choice link:** `σ(x)=1/(1+exp(−x))`; `β=ln 3` reproduces the exact prior M/N/C fixture. All behavioral Bernoulli draws and matching tie-break draws use disjoint named streams keyed by `(world,agent,time,purpose)`, not dependent on branch execution order.

### Matching operator common to all families

For **random** protocol, choose uniformly among the three perfect matchings of four actors. For **choice** protocol, each actor submits scores (ranking of the other three) according to its *family-specific partner utility*. The institution/scheduler selects the perfect matching that maximizes the **sum of all four actors' submitted scores**, with all three matchings enumerated; seeded fair tie-breaks for equal scores. Record proposals/scores at the appropriate observation level, but **never expose latent type/utility coefficients** to a lab-feasible classifier. The protocol is a **centralized clearing rule for decentralized rankings**, not proof of unconstrained peer-to-peer self-formation; a future lab would have to disclose it and implement the same rule. Everyone receives the same opportunity to rank, including families with zero preference. A random matching treatment may solicit ranks but ignores them in pairing.

**Negative controls:** equal partner utility for all candidates ⇒ uniform seeded pairing; swapping agent labels cannot alter the outcome distribution; when exogenous matching is used, preferences do not determine pairs. Endogenous **type-dependent sorting** is present only when the generator actually submits nonconstant partner utilities and the choice arm is enabled.

## 2. Six generator transition kernels (candidate, not fitted)

Let `h_i,t` denote only legitimately available *public* information before choice and `x_i,t` internal state. Each family defines a Bernoulli contribution probability and, when choice is enabled, a partner ranking distribution. All six see the same fine, real partner payoff and action schedule.

| Label | Initial internal state and contribution rule | State update | Partner preference in choice arm |
| --- | --- | --- | --- |
| **M — material enforcement** | No private preference. `P(a=1)=σ[β(f−1)]`. | None. | All candidate scores 0 (uniform tie-break). |
| **N — personal normative preference** | Actor-fixed `ν_i≥0`; `P(a=1)=σ[β(f−1+ν_i)]`. This is **personal preference**, *not a verified social norm* requiring normative expectations. | `ν_i` fixed. | Scores 0. |
| **C — conditional cooperation** | `κ_i≥0`; `P(a=1)=σ[β(f−1+κ_i m_i,t)]`. The signal `m` is the factual last partner action or the public neutral placeholder `1/2` when not revealed. | No latent learning; only the next legitimately observed `m` changes. | Scores 0. |
| **S — fixed types + partner sorting** | One persistent latent `τ_i∈{−1,+1}`; `P(a=1)=σ[β(f−1+δ τ_i)]` with `δ≥0`. Each type's action preference is fixed, independent of newly observed partners. | `τ_i` fixed; no acquired conditional rule. | `score_i(j)=ω τ_i(2s_{j,t}−1)` when candidate prior action is publicly visible; when not visible, score 0. `ω≥0`; positive types favor observed cooperation, negative types favor observed defection; the clearing rule realizes **composition** without a within-actor contribution response. |
| **L — enforcement-masked conditional learning** | Private `q_i,1∈[0,1]`; `P(a=1)=σ[β(f−1+κ_L q_i,t)]`, `κ_L≥0`. Immediate current fine affects material incentives; a learned estimate of partner cooperativeness affects preference. | After **actually observed** partner action `o_{j,t}=a_{j,t}` and current `f_t`: `w_t=r_t(1−ζ 1[f_t>0])`; `q_{t+1}=(1−α_L w_t)q_t+α_L w_t o_{j,t}`, `α_L∈[0,1],ζ∈[0,1]`. If partner action is not revealed, no learning. Fine exposure **attenuates** informativeness of observed cooperation as hypothesized in the cited work; this functional form is *ours*, not taken from authors' structural model. | Scores 0; learning from partners under matching still changes `q`. |
| **R — aspiration-based reinforcement learner** | Two latent action scores `Q_i,1(0),Q_i,1(1)`, aspiration `A_i,1`; `P(a=1)=σ[β_R(Q_i,t(1)−Q_i,t(0))]`. **No explicit normative parameter or belief/partner-history term.** | After choice `a` and actual payoff `u`: `Q_{t+1}(a)=clip(Q_t(a)+α_R(u−A_t),−Qmax,Qmax)`; unchosen `Q` unchanged; `A_{t+1}=(1−λ)A_t+λu`. Proposed `Qmax=10`, `α_R,λ∈[0,1]`. | Scores 0; any history dependence is via realized payoffs and action values, not an explicit social-cooperation preference. |

The **same physical matching and observation operator** must be applied in any direct family comparison. For family S, prior candidate actions `s_j` are used *only if public to all actors under the arm*; if the protocol suppresses them, S's scores must be zero rather than leaking latent type information. For L, observing current partner action at update time is a separately specified information permission: `r_t` refers to whether the action record becomes visible; the immediately preceding public `m` and revealed payoff must be consistent with that permission. If `r_t=0`, the own monetary payoff can still reveal an opponent's contribution under the additive payoff formula. **Therefore withholding `m` while revealing the exact own payoff would leak partner behavior**. Either (i) delay itemized payoff disclosure until after the next decision when comparing history-information interventions, or (ii) report that `r_t=0` is *not actually blind* and cannot be used as a successful independent-information arm. This **information-leak defect must be solved before freezing the design**; never call an arm “no partner-history information” while it provides the information algebraically through payoff. The exact M/N/C fixture with a scripted prior signal avoids this issue by fixing/payoff-delaying the training action.

### Parameter generating domains — proposals, not silently frozen

Candidate design-only spans: `ν_i∈[0,1.5]`, `κ_i,κ_L∈[0,1.5]`, `δ∈[0,1]`, `ω∈[0,3]`, `α_L,ζ,α_R,λ∈[0,1]`, `q_{1}∈[0,1]`, `A_1∈[−1,1]`, `Q_{1}(a)∈[−1,1]`, `β_R>0`; common `β=ln 3` in early reference tests. Generate independent **interior / boundary-overlap / adversarial out-of-family** strata with labeled denominators and uncertainty over independent societies; do *not* tune distributions based on future model-recovery test results. Type prevalence and induced nonrandom sorting **must** be prespecified. A dimension-zero/fixed-parameter special case may be appropriate for exact oracle tests, but not presented as realistic population heterogeneity.

## 3. Structural nonidentifiability and overlap to retain

1. **M is nested in N** at `ν=0`, **in C** at `κ=0`, **in S's action kernel** at `δ=0` and partner scores at `ω=0`, **in L** at `κ_L=0`. These corners stay *in the unconditional truth-generating distribution* if sampled; they count as **undetermined** on a cross-family unique-mechanism outcome, not dropped to maximize recovery.
2. **N versus C exact historical-support overlap:** when all revealed `m=1` and `ν=κ`, `P_N(a=1|f,m)=P_C(a=1|f,m)` for **every fine f**, as in the [previous exact fixture](a2-analytical-oracle-20261025.md). Varying fines alone cannot distinguish them. A *truthfully assigned scripted-partner previous defection* under identical f can do so with fixed toy parameters (**3/4 vs 1/2** at `f=1`). That is a **restricted identification example**, not a universal identification theorem.
3. **S sorting may change pair composition while leaving average individual contribution unchanged** if fixed types' probabilities do not respond to matching. The previous four-agent oracle gives mean `1/2` either way and pair-cooperation `5/16` assortative vs `3/16` mixed. That fixture is **exogenously paired**; this S generator must *actually choose/rank partners* to add endogenous sorting, and cannot inherit an identification claim from the oracle alone.
4. **L and R may mimic N/C over finite T** for special initial states, noise and exposures; **do not assert exact whole-domain equivalence without constructing the full equal observable kernels**. Conversely difference in latent update rules does **not** guarantee different *observable* actions. A six-way test must establish whether families separate under attainable intervention sequences, and declare **set identification** or “undetermined” for overlapping regions.
5. **Payoff masking risk:** in this exact game `u_i` reveals `a_j` algebraically if `a_i,f` are known. A concealed-history arm is **invalid without payoff disclosure controls**. This is a serious prospective design flaw discovered during formalization, and is a possible **STOP/REDESIGN** criterion.

## 4. Observable/assignment budget and inference rules

**Allowed in B-style prospective lab-compatible inference:** realized action `a`, publicly assigned fine `f`, actual match ID and regime `z`, legitimate public history `m` / revelation `r`, observed publicly shared ranking/proposals if the future experiment actually records them, realized feedback/payoff **at the time it is made visible**, session and period. No true type `τ`, personal norm `ν`, conditional weight `κ`, latent belief `q`, RL score `Q` or aspiration `A`. No output from counterfactual clones of the *same unit*. Training/testing split over **independent worlds**, not within-actor rows counted as independent.

**Four separately labeled regimes** remain as in [#36](https://github.com/davletovb/social-emergence-lab/issues/36): synthetic paired forks A (count all fork costs, dependent parents), one-realized-history prospective assignments B, genuinely historical Galbiati fine-per-match C (no endogenous sorting/history-reveal treatments), and latent-state upper bound D.

**Classification rule:** fit every nominated family using identical allowed budget; construct a predeclared loss/tolerance/uncertainty **admissible-set of model families**. **Exactly one identifiable family** ⇒ “recovered”; two or more ⇒ **undetermined** even if the smallest predictive parameterization wins for forecasting. Nested boundary cases stay in the unconditional class denominator. Primary outcome proposed: minimum family-wise identifiable recovery, with honest variation across parameter/noise/misspecification strata. No predictions from this document are scored observations.
