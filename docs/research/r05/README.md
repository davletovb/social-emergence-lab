## Reusable dossier template
1. Narrow question, contribution type and **strongest permitted conclusion**.
2. Two or more rival mechanisms, **the same intervention operator for every rival**, predeclared possible informative null or structural nonidentification.
3. Required **observations, assignments, timings and independent units**; synthetic versus human evidence kept apart.
4. Original predecessors (original text section actually inspected, not generic citation), closest gap and access/rights status.
5. Small exact/oracle feasibility, compute limits, failure and reopen rule.
6. Tier-1 screening status clearly labeled; no score until Tier-2 source inspection.

All six have the same *structure*, but the actual original articles accessible differ: no claim of identical research depth or that abstract checks equal full peer-reviewed source audits. No Github Actions or simulation runs used to create this first pass.
