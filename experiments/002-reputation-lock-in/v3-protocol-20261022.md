# Experiment 002 V3 — Structural memory versus active reputation lock-in

**Protocol frozen 2026-10-22, before any V3 outcomes.** Research status: a *new exploratory validation stage*, not preregistration or independent empirical confirmation. Builds on [Issue #19](https://github.com/davletovb/social-emergence-lab/issues/19) and the 36-parent H1 falsification gate. Prior 98000–98035 development seeds are **never used as V3 confirmations**.

## Competing accounts and test

- **Structural memory (H0 mechanism):** the old advantage persists through links present at correction checkpoint τ. Under uniform deletion, each of N·d links has the same hazard, so S(t) ≈ (1 − 1/(N·d))^(floor(t/m)), where m is the number of opportunities between rewirings. The implied half-life is about 110/551/1102 events at m=2/10/20 when N=20,d=4. This **is not an exact prediction for belief-based deletion**; report the observed survival curve there.
- **Active feedback (H1 mechanism):** after resetting reputation information to truth, newly formed/re-added edges and conditional selection persistently generate a *positive opportunity excess* beyond the inherited-edge exposure. The primary exploratory readout is **new-link exposure + selection**, with a separately reported same-cell δ=0 counterpart; no late total gap is sufficient by itself.
- For each cell, also report continually surviving checkpoint-edge exposure, actual survivor fraction, inherited exposure per survivor, expected total (= inherited + new + selection), realized opportunity gap, and residual stochastic innovation. A structural prediction **must use that cell's own** checkpoint exposure, since different rewiring rates change the pre-correction graph.
- The late window is opportunities 501–600; windows 201–300, 301–400, 401–500 and 501–600 are all shown. The survivor count is recorded after each event while exposure is pre-event, yielding at most one rewire-step offset; document this rather than pretending the two are mathematically simultaneous.

## Fixed factorial

The existing Rust engine already supports the required factors, so no core Hiyal or legacy reputation semantics are modified.

| Mechanism label | Deletion | Addition κ | Meaning |
| --- | --- | ---: | --- |
| `random-turnover` | Uniform eligible-edge removal | 0 | Reputation-free network churn |
| `belief-deletion` | Remove the lowest-belief neighbor | 0 | Preferred deletion only |
| `full-feedback` | Remove the lowest-belief neighbor | 6 | Preferred deletion + reputation-preferred addition |

Cross with `rewire_every ∈ {2,10,20}`, holding N=20,d=4,β=4,ε=0.1,δ=0.2,τ=200,T=600, learning=public_learning=0.1 and exactly the original graph sampler. Each cell runs the identical four intervention arms under δ=0.2 and δ=0, with matched initial setup but independently evolving parent/fork histories. The δ=0 arm is an expectation-symmetry negative control, not proof each realized sequence is zero. No claimed separate causal identification of exposure and selection as natural mediators: they form an accounting identity. Contrasts of model rules can interact.

## Feasibility sample (not an outcome-estimating sample)

The **nine fresh seeds 120200–120208 are fixed in row-major order**: turnover m=2,10,20, and within each turnover `random-turnover`, `belief-deletion`, `full-feedback`. One *independent parent seed* per cell (with the within-seed δ=0 control) is an **engineering smoke test**: it checks that every cell runs, replays and verifies at N=20 and records its cost. With one parent per cell it cannot estimate variance, so it does not set the main sample size. **Nine cells are not nine replications of the same treatment**, and this sample supports no intervals or directional claims. Never silently replace failed seeds, and report even a negative result. The main grid below is frozen now and changes only if a cell fails to run.

## Frozen main grid and decision rule

Frozen 2026-10-22, before any V3 outcome. Constants are in `src/reputation_v3.rs` and the rule is executable as `scripts/v3-decision-002.jq`.

- **Sample:** 48 fresh parents per cell, seed `130000 + 100·cell + i` for row-major cell 0–8 (as in the pilot) and i = 0–47. These are disjoint from every seed used so far (a test checks this). Stage A is the three full-feedback turnover cells (2, 5 and 8: m = 2, 10, 20), which test the slow-relaxation prediction directly; Stage B is the other six cells. Each stage is run in full, and every cell is reported.
- **Why 48:** in the 36 V2 pairs at m=10, which used exactly the full-feedback settings, the per-parent sd was 0.068 for late new links + selection and 0.091 for the structural excess below. With 48 parents, the 95% half-widths are about 0.020 and 0.026. If slow relaxation is true and those variances hold, the rule then classifies a cell as slow relaxation with probability about 0.92, against 0.79 with 36 parents. Cost is about 70 s per matched pair in release: about 40 minutes for Stage A and 2 hours for the full grid on 4 cores, run manually or as sharded jobs, never in routine CI.
- **Quantities per parent** (δ=0.2, information-only fork):
  - `nps` = late (501–600) new-link exposure + conditional selection;
  - `c` = first-window (201–300) surviving-link exposure ÷ first-window surviving fraction, the exposure each surviving checkpoint link carries;
  - `excess` = late expected gap (surviving + new + selection) − `c` × late surviving fraction.
  
  Slow relaxation predicts both `nps` and `excess` are near zero: the late gap is the first-window exposure per link times the links still present.
- **Rule per cell** (95% t intervals over parents, t = 2.011741 for df = 47, margin ±0.05, about a quarter of the V2 late gap of +0.218):
  - **slow relaxation:** the `nps` interval contains 0, and both the `nps` and `excess` intervals lie within ±0.05;
  - **regeneration:** the `nps` interval lies entirely above 0; report whether its mean also exceeds the margin;
  - **inconclusive:** anything else.
- **Controls:** the same quantities at δ=0 should be near zero. An `nps` interval excluding zero there is a symmetry flag for investigation, not an exclusion rule. For random-turnover cells, report the observed surviving fraction per window against the uniform-hazard prediction.
- **Calibration, not evidence:** applied to the 36 V2 pairs (m=10, full feedback; not V3 seeds), the rule gives `slow_relaxation`: `nps` +0.0016 (−0.0214, +0.0246) and `excess` +0.0054 (−0.0255, +0.0363).
