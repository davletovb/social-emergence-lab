**Protocol frozen 2026-10-22, before any V3 outcomes.** Research status: a *new exploratory validation stage*, not preregistration or independent empirical confirmation. Builds on [Issue #19](https://github.com/davletovb/social-emergence-lab/issues/19) and the 36-parent H1 falsification gate. **Amended 2026-10-22, after Stage A and before any Stage B run:** [Amendment 1](#amendment-1--adopted-2026-10-22-after-stage-a-and-before-any-stage-b-run) changes the decision rule for Stage B only. ## Competing accounts and test

- **Structural memory (H0 mechanism):** the old advantage persists through links present at correction checkpoint τ. Under uniform deletion, each of N·d links has the same hazard, so S(t) ≈ (1 − 1/(N·d))^(floor(t/m)), where m is the number of opportunities between rewirings. The implied half-life is about 110/551/1102 events at m=2/10/20 when N=20,d=4. This **is not an exact prediction for belief-based deletion**; report the observed survival curve there.
- **Active feedback (H1 mechanism):** after resetting reputation information to truth, newly formed/re-added edges and conditional selection persistently generate a *positive opportunity excess* beyond the inherited-edge exposure. The primary exploratory readout is **new-link exposure + selection**, with a separately reported same-cell δ=0 counterpart; no late total gap is sufficient by itself.
- For each cell, also report continually surviving checkpoint-edge exposure, actual survivor fraction, inherited exposure per survivor, expected total (= inherited + new + selection), realized opportunity gap, and residual stochastic innovation. A structural prediction **must use that cell's own** checkpoint exposure, since different rewiring rates change the pre-correction graph.
- The late window is opportunities 501–600; windows 201–300, 301–400, 401–500 and 501–600 are all shown. The survivor count is recorded after each event while exposure is pre-event, yielding at most one rewire-step offset; document this rather than pretending the two are mathematically simultaneous.

## Fixed factorial

The existing Rust engine already supports the required factors, so no core Hiyal or legacy reputation semantics are modified.

| Mechanism label | Deletion | Addition κ | Meaning |
| --- | --- | ---: | --- |
| `random-turnover` | Uniform eligible-edge removal | 0 | Reputation-free network churn |
| `belief-deletion` | Remove the lowest-belief neighbor | 0 | Preferred deletion only |
| `full-feedback` | Remove the lowest-belief neighbor | 6 | Preferred deletion + reputation-preferred addition |

Cross with `rewire_every ∈ {2,10,20}`, holding N=20,d=4,β=4,ε=0.1,δ=0.2,τ=200,T=600, learning=public_learning=0.1 and exactly the original graph sampler. Each cell runs the identical four intervention arms under δ=0.2 and δ=0, with matched initial setup but independently evolving parent/fork histories. The δ=0 arm is an expectation-symmetry negative control, not proof each realized sequence is zero. No claimed separate causal identification of exposure and selection as natural mediators: they form an accounting identity. Contrasts of model rules can interact.

## Feasibility sample (not an outcome-estimating sample)

The **nine fresh seeds 120200–120208 are fixed in row-major order**: turnover m=2,10,20, and within each turnover `random-turnover`, `belief-deletion`, `full-feedback`. One *independent parent seed* per cell (with the within-seed δ=0 control) is an **engineering smoke test**: it checks that every cell runs, replays and verifies at N=20 and records its cost. With one parent per cell it cannot estimate variance, so it does not set the main sample size. **Nine cells are not nine replications of the same treatment**, and this sample supports no intervals or directional claims. Never silently replace failed seeds, and report even a negative result. The main grid below is frozen now and changes only if a cell fails to run.

## Frozen main grid and decision rule

Frozen 2026-10-22, before any V3 outcome. Constants are in `src/reputation_v3.rs` and the rule is executable as `scripts/v3-decision-002.jq`.

- **Sample:** 48 fresh parents per cell, seed `130000 + 100·cell + i` for row-major cell 0–8 (as in the pilot) and i = 0–47. These are disjoint from every seed used so far (a test checks this). Stage A is the three full-feedback turnover cells (2, 5 and 8: m = 2, 10, 20), which test the slow-relaxation prediction directly; Stage B is the other six cells. Each stage is run in full, and every cell is reported.
- **Why 48:** in the 36 V2 pairs at m=10, which used exactly the full-feedback settings, the per-parent sd was 0.068 for late new links + selection and 0.091 for the structural excess below. With 48 parents, the 95% half-widths are about 0.020 and 0.026. If slow relaxation is true and those variances hold, the rule then classifies a cell as slow relaxation with probability about 0.92, against 0.79 with 36 parents. Cost is about 95 s per matched pair in release, including the batch verification (a 3-parent smoke run of cell 5 took 110 s on 4 cores): about an hour for Stage A and three hours for the full grid on 4 cores, run manually or as sharded jobs, never in routine CI.
- **Quantities per parent** (δ=0.2, information-only fork):
  - `nps` = late (501–600) new-link exposure + conditional selection;
  - `c` = first-window (201–300) surviving-link exposure ÷ first-window surviving fraction, the exposure each surviving checkpoint link carries;
  - `excess` = late expected gap (surviving + new + selection) − `c` × late surviving fraction.
  
  Slow relaxation predicts both `nps` and `excess` are near zero: the late gap is the first-window exposure per link times the links still present.
- **Rule per cell** (95% t intervals over parents, t = 2.011741 for df = 47, margin ±0.05, about a quarter of the V2 late gap of +0.218):
  - **slow relaxation:** the `nps` interval contains 0, and both the `nps` and `excess` intervals lie within ±0.05;
  - **regeneration:** the `nps` interval lies entirely above 0; report whether its mean also exceeds the margin;
  - **inconclusive:** anything else.
- **Controls:** the same quantities at δ=0 should be near zero. An `nps` interval excluding zero there is a symmetry flag for investigation, not an exclusion rule. For random-turnover cells, report the observed surviving fraction per window against the uniform-hazard prediction.
- **Calibration, not evidence:** applied to the 36 V2 pairs (m=10, full feedback; not V3 seeds), the rule gives `slow_relaxation`: `nps` +0.0016 (−0.0214, +0.0246) and `excess` +0.0054 (−0.0255, +0.0363).

### Running the main grid

Each cell is a separate sealed batch, so cells can run on different machines or jobs. The frozen design comes from `reputation-v3 plan <cell>`, the only place the seeds and constants are defined.

```bash
# Manual ONLY, from a clean checkout. Stage A: cells 2, 5 and 8.
for cell in 2 5 8; do
  bash scripts/v3-grid-002.sh /absolute/new/v3-grid-cell-$cell "$cell" --jobs 4
done
# Each run ends by verifying its own batch and printing the decision and the
# SHA256SUMS digest; record the digest outside the evidence directory.
bash scripts/verify-v3-grid-002.sh /absolute/new/v3-grid-cell-5 --digest <recorded-sha256> --jobs 4
```

A cell batch holds `batch-plan.json` (the frozen design plus source and Hiyal revisions), one `parent-<seed>` directory per planned seed (both matched runs, `paired-report.json` and `cell-summary.json`), `decision.json` and `SHA256SUMS`. The verifier checks the seal and its exact coverage, that the plan equals the frozen design, that exactly the planned parents are present, every parent's Hiyal journals, and it re-derives every cell summary and the decision. It compares values rather than jq's number spelling. A failed run leaves `FAILURE.txt` and is reported, never rerun with other seeds.

`--smoke` runs the same pipeline on three parents per cell with non-frozen seeds (140000 + 100·cell + i) as an engineering dry run. Its plan is marked `ENGINEERING_SMOKE_NOT_EVIDENCE`, and its decision is not evidence.

## Amendment 1 — adopted 2026-10-22, after Stage A and before any Stage B run

**Why.** The [Stage A results](results/v3-stage-a-20261022/README.md) exposed two gaps in the frozen rule:
- **No label for a significantly negative result.** Cell 2 (m=2) was classified inconclusive although its `nps` interval, (−0.072, −0.003), excludes zero on the side opposite to regeneration. "Inconclusive" thus mixed "could not decide" with "decided against regeneration".
- **No distribution-free check.** Two of the three δ=0 controls were flagged by their t intervals, with opposite signs, and the cell 2 flag came from a right tail.

This amendment was written after seeing those outcomes. It changes nothing about Stage A, whose decisions stay those of the frozen rule, as committed. For Stage B it is fixed before any Stage B parent has been run, main grid or smoke.

**Rule for Stage B.** The rule is `scripts/v3-decision-002-amendment-1.jq`, with constants in `src/reputation_v3.rs`. Stage B plans (`reputation-v3 plan <cell>`) name the rule, so the grid scripts apply it to Stage B cells and the frozen rule to Stage A cells.
1. **Four categories.** Same `nps`, `excess`, t intervals and margin as the frozen rule:
   - **slow relaxation** and **regeneration:** as frozen;
   - **compensation:** the `nps` interval lies entirely below 0, so new links and selection work *against* the formerly favoured group. Report whether its mean is also below −0.05;
   - **inconclusive:** anything else.
   
   The output also records what the frozen rule would have said.
2. **Robustness checks, reported for every cell:**
   - **Median intervals:** exact distribution-free 95% intervals for the medians of `nps` and `excess`, from order statistics [x₍ₖ₎, x₍ₙ₊₁₋ₖ₎]. For 48 parents these are x₍₁₇₎ and x₍₃₂₎, with coverage 97.1%.
   - **Sign test:** an exact two-sided sign test of `nps`; exact zeros are dropped.
   - **Median rule:** the same four-way rule applied to the median intervals. A cell is **robust** when the median rule agrees with the t-interval rule.
   - **Windows:** `nps` t intervals in each of the four windows, 201–300 to 501–600. These overlap in parents, so they show stability, not independent replication.
   - **Control variate:** `nps` adjusted by the same parent's δ=0 `nps`. The δ=0 mean is exactly 0, so the intercept of the least-squares fit of `nps` on null `nps` estimates the same mean as `nps`, with the variance the two sides share removed. Its t interval uses 46 df (t = 2.012896).
3. **Null control.** Labels are a uniformly random balanced subset drawn from their own setup stream (`setup` in `src/reputation.rs`), so the complementary labelling is equally likely. At δ=0 every prior is 0.5, and selection, performance draws, rewiring and the information reset never read the labels; only the measurements do. The complementary labelling therefore gives the same run with every signed quantity flipped, so each δ=0 quantity is exactly symmetric about 0. The sign test is then exact whatever the distribution's shape.
   - **The flag is now a sign test at p < 0.05**; the t-interval flag is still reported. For 48 parents the sign test's exact size is 2.9%.
   - As before, a flag calls for investigation, not exclusion.
4. **Reading a stage.** For Stage B, item 1 of the review above applies this rule in place of the frozen one, and this reading replaces item 2:
   - **No active reputation lock-in** in a stage if no cell is regeneration under either the t rule or the median rule.
   - Report each cell as slow relaxation (structural persistence), compensation (structural persistence, with new links that counteract it), or inconclusive. Report a label that the median rule does not reproduce as not robust.
   - If any cell is regeneration under either rule, stress-test it as in item 2 above before any claim.

**Engineering check after adoption.** The amended pipeline was run end to end on a smoke run of cell 0: three parents on non-frozen seeds 140000–140002, 91 s on 4 cores. It ran, sealed and verified, and its decision had the amended structure. It is not evidence, and its outcome was not inspected.

**Stage A under Amendment 1** is reported post hoc and descriptively in the [Stage A results](results/v3-stage-a-20261022/README.md#post-hoc-robustness-under-amendment-1). It does not replace the frozen Stage A outcome.
